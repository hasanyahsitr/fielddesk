# Roadmap

Priorities for feedback and contribution, not delivery dates or completed features.

## Next: make first use easier

- Test the preview on clean Windows 10/11 machines and removable drives.
- Improve the setup check with clearer missing-tool and model diagnostics.
- Add a reviewed model catalog and guided local runtime/model setup, with download size and model license information.
- Improve chat feedback for slow initial loads, context limits and interrupted responses.
- Collect feedback on the English/Turkish UI and keyboard navigation.

## Then: maintain a dependable toolkit

- Expand the app catalog based on actual requests, with reproducible metadata review.
- Add repeatable release checks and a reviewed process for catalog updates.
- Improve project and document workflows after real use identifies friction.
- Plan backup/restore UX with explicit handling of encrypted credentials and drive changes.

## Later: evaluate rather than promise

- Additional model backends and hardware acceleration.
- More platforms, if there is demand and maintainers can test them.
- Carefully scoped automation with visible permissions, review and cancellation.

The current assistant is a chat tool. General computer/phone control, autonomous professional work and guaranteed AI accuracy are not shipped capabilities.
