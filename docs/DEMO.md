# About the FieldDesk demo

[Watch the video](https://github.com/hasanyahsitr/fielddesk/releases/download/v0.8.0/FieldDesk-0.8.0-demo.mp4) · [First-run guide](FIRST_RUN.md)

The demo is a real browser capture of FieldDesk 0.8.0 on Windows x64 in a separate sample workspace. Documents and names are fictional. The GIF is a shorter edited overview; the video retains the recorded interaction sequence with a title and caption.

The recording shows a prepared Notepad++ entry, opening the 30-package catalog, downloading and verifying jq, previewing and merging two PDFs, searching an indexed project note, and switching between English and Turkish. Notepad++ was downloaded and prepared before recording. The PDF output was checked to contain two pages and the original input hashes were preserved.

The video has no audio. Read the [first-run guide](FIRST_RUN.md) for the steps in text. Downloads need network access; document workflows and search run locally. This capture does not demonstrate installation on every Windows configuration, an OCR engine, AI model setup or an AI answer. These components have their own requirements. Some dynamic PDF messages in the English UI still use Turkish wording in the preview.

The approximately 23 MB Windows release contains the FieldDesk launcher and its Python dependencies. Third-party apps, model weights and personal workspaces are downloaded or supplied separately. The demo is a separate optional download.
